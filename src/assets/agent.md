# Assets Agent Guide

## Scope
Static assets used by the native app (images, icons, media).

## Prompt Update Rule
After prompts that change this folder, update this file with new asset paths and where they are used.

## Fast Navigation
- Keep file names stable to avoid broken imports.
- Note any large media additions and related screen/component usage.

## Verify
- Run app and confirm assets load without red screen or missing resource warnings.
